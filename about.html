关于这个站

这是一个关于 Minecraft 的个人笔记站，记录我在游戏里的生存经验、用过的模组推荐，还有自己建的一些建筑。

为什么做这个站

玩 MC 这么久，踩过不少坑也攒了不少经验。想把这些东西整理下来，方便自己回顾，也说不定能帮到其他玩家。

关于我

一个普通的 MC Java 版玩家，喜欢生存模式和搞一些小建筑。目前主要玩 1.21.8 版本，偶尔装模组玩整合包。

这个站用什么做的

纯手写 HTML + CSS，没有用框架。代码放在 GitHub 上，通过 GitHub Pages 发布。
