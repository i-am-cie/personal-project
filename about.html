关于我这个老玩家

从 1.7.10 版本开始玩的，算下来快十年了。最开始是网易中国版，后来转了 Java 版，现在用 PCL 启动器，装模组玩整合包。

入坑经历

最开始是同学拉我玩的，网易版手机端。那时候连工作台都不会做，第一天晚上被僵尸追着跑了半张图。后来慢慢学会了，开始玩生存，再后来开始装模组，一去不复返。

转 Java 版是因为网易版模组太少了，想玩暮色森林都找不到。当时折腾了好久才弄好 PCL，又花了一下午才把模组装明白。现在回头看，那时候真的啥都不懂。

玩过的服务器

最开始玩网易版的花雨庭，起床战争打了几百局，最高段位是钻石。后来玩 Hypixel，但是延迟太高了，打起床战争反应永远慢半拍，被虐得怀疑人生。

现在基本不怎么玩服务器了，偶尔和朋友玩 EaseCation 的空岛战争。人老了，手速跟不上年轻人了，还是玩单机生存舒服。

碰到的趣事

  • 第一次打末影龙 — 带了一堆弓，结果龙过来的时候紧张得手抖，箭全射歪了。最后是用拳头把龙打死的，说出来没人信。
  • 建房子建到一半 — 建了个大城堡，结果第二天上线发现苦力怕把我家炸了个洞。从那以后我家门口永远插满火把。
  • 玩惊变 100 天 — 撑了 40 天，晚上出门找食物，被一群僵尸堵在角落里，活生生挠死。存档直接删了，不玩了。
  • 和朋友联机 — 朋友说他建了个超级大别墅，我跑过去一看，就是个放大版的火柴盒，我们笑了半个小时。

喜欢的 UP 主

B站关注了好几个 MC UP 主：卡慕SaMa、马里奥红叔、萝卜吃米洛，他们的多人生存系列我每期都看。还有那个用 MC 还原家乡的 Offical-Bean，真的牛，一砖一瓦盖出来的。

抖音上喜欢看那些搞笑的 MC 短视频，比如"当 100 名玩家追捕 7 位 UP"那种，方块制片局做的，策划是真的用心。

这个站用什么做的

纯手写 HTML + CSS，没有用框架。代码放在 GitHub 上，通过 GitHub Pages 发布。本来是课程作业，后来想着既然要做，就认真做个自己真的想用的站。
